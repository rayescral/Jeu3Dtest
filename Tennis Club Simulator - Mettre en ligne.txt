=====================================================================
  TENNIS CLUB SIMULATOR — Mettre le jeu en ligne (comme Justice Deck)
=====================================================================

Le jeu est fait de plusieurs fichiers : il doit être servi par un site
web (comme sur Claude). Netlify le fait gratuitement, en glisser-déposer.
Compte 2 minutes.


---------------------------------------------------------------------
 ÉTAPE 1 — Préparer le dossier
---------------------------------------------------------------------
1. Récupère le dossier du jeu :
     - soit le fichier « tennis-club-simulator.zip » envoyé par Claude,
     - soit sur GitHub : dépôt rayescral/Jeu3Dtest, branche
       claude/gallant-pasteur-0xlwe2, bouton vert « Code » > Download ZIP.
2. Clic droit sur le ZIP > « Extraire tout… » > « Extraire ».
3. Vérifie que le dossier obtenu contient bien « index.html »,
   « style.css » et le dossier « src ».


---------------------------------------------------------------------
 ÉTAPE 2 — Mettre en ligne (Netlify Drop)
---------------------------------------------------------------------
1. Va sur https://app.netlify.com/drop (connecte-toi avec le même
   compte que pour Justice Deck, sinon le site est supprimé au bout
   d'une heure).
2. Glisse-dépose le dossier extrait (celui qui contient index.html)
   dans la zone de la page.
3. Netlify te donne une adresse du type
   https://nom-aleatoire-123.netlify.app — c'est ton jeu.
   Tu peux la renommer : « Site configuration > Change site name »
   (par exemple tennis-club-simulator.netlify.app).


---------------------------------------------------------------------
 ÉTAPE 3 — Jouer
---------------------------------------------------------------------
Ouvre l'adresse dans Chrome, Edge ou Firefox sur ton ordinateur.
Clique dans le jeu pour capturer la souris, Échap pour la pause.
Ta partie est sauvegardée dans le navigateur.

Mises à jour du jeu : dans Netlify, ouvre ton site > onglet
« Deploys », et glisse à nouveau le dossier dans la zone prévue.
